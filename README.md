# NotesApp

Простое приложение для заметок на Android, написанное на **Kotlin** с использованием **Jetpack Compose** и **Material 3**. Сделано в качестве демо-проекта для трудоустройства Android-разработчиком.

## Стек

- **Kotlin** — основной язык
- **Jetpack Compose** — декларативный UI
- **Material 3** — оформление
- **ViewModel + StateFlow** — состояние и архитектура (MVVM-подобная)
- **Gradle (Kotlin DSL)** — сборка

## Экраны

- Список заметок (LazyColumn, карточки)
- Создание новой заметки (FAB → форма с сохранением и отменой)

## Сборка

Требуется Android Studio (Giraffe или новее) и Android SDK.

```bash
./gradlew assembleDebug
```

APK будет в `app/build/outputs/apk/debug/app-debug.apk`.
